# 부동산 공급 뉴스 카드뉴스 운영·제작 규칙

이 문서는 재개발·재건축·정비사업·청약·신도시·교통/SOC 관련 뉴스 수집부터 기사 선정, 카드뉴스 제작, 검수까지의 기준 문서다.

## 1. 전체 운영 흐름

1. 매일 오전 7시 30분 뉴스 기사만 수집한다.
2. `ARTICLES.md`에 번호, 제목, 출처, 기사 링크를 기록한다.
3. 차단 매체와 오래된 기사 재게시 사례를 제외한다.
4. 사용자가 기사 번호를 선택한다.
5. 선택된 기사는 서로 합치지 않고 기사 1건당 카드뉴스 1세트로 제작한다.
6. 각 세트는 5장 이상 8장 이하로 구성한다.
7. 기사 내용, 수치, 일정, 사업 단계를 검수한 뒤 게시한다.

## 2. 기본 슬라이드 구조

### 1장 — 호기심 표지

- 대중의 궁금증, 불편, 놓치기 쉬운 조건을 한 문장으로 제시한다.
- 강한 표현을 쓰더라도 기사에서 확인되지 않은 확정·수혜·가격 상승 표현은 금지한다.
- 핵심 제목은 68~70px, 최대 폭 780px을 지킨다.
- 예: `이 지역 1,919가구 공급, 가장 먼저 바뀌는 곳은?`

### 2장 — 실용 혜택 표지

- 첫 장을 놓친 사람도 내용을 이해할 수 있는 두 번째 표지로 설계한다.
- 구체적인 숫자, 대상지, 일정, 자격, 체크포인트를 제시한다.
- 예: `면목본동·성내동·정릉동·화양동 핵심 계획 한눈에 보기`

### 3장 이후 — 저장형 정보

- 한 슬라이드에는 하나의 질문 또는 하나의 결론만 담는다.
- 숫자 카드, 단계별 흐름, 전후 비교, 체크리스트, 지도·구역도 중심으로 구성한다.
- 기사 문장을 길게 옮기지 않고 모바일에서 한 번에 읽히는 문장으로 요약한다.
- 어려운 행정·법률 용어는 쉬운 표현을 먼저 쓰고 필요한 경우 괄호로 원어를 병기한다.

### 마지막에서 두 번째 장 — 요약 보드

- 한 장만 저장하거나 캡처해도 핵심을 확인할 수 있게 만든다.
- 슬라이드 배지에는 `핵심 요약` 또는 `한눈에 보는 핵심 요약`만 사용하고 `저장용` 문구는 생략한다.
- 기본 항목: 위치, 현재 단계, 공급 규모, 주요 일정, 확인할 위험·주의사항.

### 마지막 장 — CTA

- 반드시 한 가지 이상의 명확한 행동을 요청한다.
- 기본 문구: `일정이 바뀔 수 있으니 저장해 두고 다시 확인하세요.`
- 선택 문구: `이 지역을 기다리는 분에게 공유해 주세요.`
- 실제 제공물이 없는 무료 전자책·프로필 링크 문구는 사용하지 않는다.

## 3. 주제별 기획 기준

### 교통·SOC

- 핵심 질문: 노선이 언제, 어느 단계까지 진행됐고 생활권이 어떻게 달라지는가?
- 필수 정보: 사업 단계, 개통 목표 시기, 지연 여부, 노선도, 환승·대체 노선, 인근 주요 주거지.
- `착공 확정`, `수혜 지역` 등의 표현은 기사 근거가 있을 때만 사용한다.

### 재개발·재건축·정비사업

- 핵심 질문: 지금 어느 단계이며 다음 절차는 무엇인가?
- 필수 정보: 쉬운 단계 설명, 예상 공급 세대수, 사업 범위, 다음 절차, 전매·조합원 자격 등 주의사항.
- `9부 능선`, `이주 시작` 등은 실제 인허가·공고가 확인된 경우에만 사용한다.

### 청약·신도시

- 핵심 질문: 누가 신청할 수 있고 언제 얼마의 자금이 필요한가?
- 필수 정보: 일정, 특별·일반공급 물량, 자격, 분양가·주변 시세 비교, 계약금, 거주의무·전매제한.
- 예상 가격이나 시세차익은 기사 근거와 기준일을 함께 표시한다.

## 4. 이미지 사용 기준

- 뉴스 기사에 포함된 조감도, 위치도, 구역도, 배치도, 교통망도만 사용한다.
- 기사 밖의 별도 공식 원문을 다시 찾지 않는다.
- 인물 사진, 현장 취재 사진, 장식용 사진은 사용하지 않는다.
- 교통 콘텐츠는 기사에 포함된 지도·노선도를 사용하고 필요한 경우 강조선을 추가한다.
- 이미지 하단에 `기사 내 자료 · 매체명 / 제공기관` 형식으로 출처를 표시한다.
- 사용 조건이 불분명하면 사용자 확인 전까지 카드뉴스에 삽입하지 않는다.
- 이미지가 없거나 승인되지 않으면 숫자 카드, 도식, 타임라인으로 대체한다.

## 5. 디자인 시스템

- 크기: 1080×1350px, 4:5 세로형 PNG.
- 1:1 피드 안전영역: X 150~930px, Y 170~1170px.
- 색상은 3색을 기본으로 제한한다.
  - 배경: `#FFFFFF`, `#F8F9FA`, `#EAF0FB`
  - 주조색: `#0D1B3E`, `#1F5ADB`
  - 강조색: `#F5A623`
- 제목: Pretendard Bold/ExtraBold.
- 본문: Pretendard Regular/Semibold.
- 본문은 모바일에서 읽을 수 있도록 24px 이상을 기본으로 한다.
- 표지 레이아웃은 이미지형, 숫자형, 질문형, 비교형 4종 안에서 반복 사용한다.
- 카드마다 출처, 기사 날짜, 브랜드 워터마크를 하단에 표시한다.

## 6. 저장성과 검색 유입

- 콘텐츠는 트렌드 요약, 단계별 가이드, 일정표, 체크리스트, 전후 비교 형태로 재구성한다.
- 캡션 첫 문단에 지역명, 사업명, 재개발·청약·교통 등 핵심 검색어를 자연스럽게 포함한다.
- 해시태그는 광범위 태그보다 지역명·사업명·공급유형을 우선한다.
- 게시 후 핵심 슬라이드를 스토리에 공유할 수 있도록 독립적으로 이해되는 제목을 쓴다.

## 7. 게시 전 검수

- [ ] 기사 1건당 별도 1세트인가?
- [ ] 전체 장수가 5~8장인가?
- [ ] 1장과 2장이 각각 독립 표지 역할을 하는가?
- [ ] 마지막에서 두 번째 장이 저장 가능한 요약 보드인가?
- [ ] 마지막 장에 저장·공유 CTA가 있는가?
- [ ] 수치, 날짜, 공급 규모가 기사와 일치하는가?
- [ ] 발표·심의·인가·착공·입주 단계를 혼동하지 않았는가?
- [ ] 사용 이미지가 기사 내 조감도·위치도 계열인가?
- [ ] 이미지 출처와 기사 출처가 표시됐는가?
- [ ] 모든 핵심 텍스트가 1:1 안전영역 안에 있는가?
- [ ] 모든 PNG가 1080×1350px인가?

### 문맥 검증 게이트

- 기사에서 숫자, 거래 사례, 발언, 정책 내용을 떼어내기 전에 앞뒤 문단을 함께 확인한다.
- `기존 상황 → 새로 발생한 사건 → 예상되는 영향`의 시간 순서를 먼저 정리한다.
- 상관관계를 인과관계로 바꾸지 않는다. 기사에 없는 원인이나 결과를 임의로 연결하지 않는다.
- 발표, 요청, 검토, 심의 통과, 확정, 착공, 준공을 서로 다른 단계로 구분한다.
- 가격·신고가 사례를 사용할 때는 왜 기사에 등장했는지 배경과 새 변수를 함께 설명한다.
- 전망이나 업계 분석은 확정 사실과 분리하고 `가능성`, `우려`, `분석`으로 표시한다.
- 기사 본문만으로 주체, 시점, 인과관계 또는 수치 기준을 명확히 설명할 수 없으면 추정하지 않는다.
- 문맥이 애매한 문장·수치·사례는 슬라이드에서 제외한다.
- 핵심 주장 자체가 애매하거나 교차 확인이 불가능하면 해당 기사를 카드뉴스 제작 대상에서 제외한다.
- 정보량이 줄더라도 애매한 내용을 채워 넣기 위해 장수를 늘리지 않는다. 최소 5장을 충족할 수 없으면 제작을 보류한다.

#### 문맥 검수 체크리스트

- [ ] 원인과 결과의 순서가 기사와 일치하는가?
- [ ] 기존 흐름과 새로 발생한 변수를 구분했는가?
- [ ] 요청·검토 단계의 내용을 의무·확정으로 표현하지 않았는가?
- [ ] 거래가격이나 수치가 본문의 핵심 논지를 왜곡하지 않는가?
- [ ] 기사에 없는 해석이나 단정이 추가되지 않았는가?
- [ ] 애매한 정보는 과감히 제외했는가?

## 8. 도달 보완 운영

- 카드뉴스 게시 후 핵심 장을 인스타그램 스토리에 공유한다.
- 링크 스티커·설문 기능은 실제 링크 또는 질문이 있을 때만 사용한다.
- 릴스를 사용하지 않는 기간에는 주 3회 이상 발행을 목표로 하되, 검수되지 않은 기사를 채우기 위해 게시하지 않는다.
