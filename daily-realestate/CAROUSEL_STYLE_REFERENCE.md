# 카드뉴스 디자인 레퍼런스 기준

사용자가 제공한 `hidden_goyang` 계열 카드뉴스는 직접 복제하지 않고, 다음 요소만 참고한다.

## 가져올 점

- 한 장에 정보 하나를 분명히 보여주는 구조
- 모바일에서 큰 제목과 짧은 보조 문장으로 읽히는 구성
- 기사 출처와 날짜를 카드 안에 작게 남기는 습관
- 표지 → 핵심 변화 → 숫자 → 확인 필요사항 → 요약의 흐름
- 캡션에 카드 내용을 다시 정리하고 해시태그를 붙이는 방식

## 그대로 따라 하지 않을 점

- 동일한 계정 핸들 위치, 노란 점, 슬라이드 카운트 위치 조합
- 사진 위 검은 오버레이와 노란색만 쓰는 단일 인상
- 가로줄 표를 그대로 복제한 정보 배치
- “정말로 생기나?” 같은 레퍼런스 특유의 문장 리듬 반복
- 특정 지역 계정처럼 보이는 로컬 커뮤니티형 톤

## 우리 계정의 방향

- 톤: 부동산 공급 뉴스 브리핑 / 리서치 노트
- 인상: 신뢰감 있는 네이비 기반, 도시계획·지도·보고서 느낌
- 포인트 컬러: 블루를 주조색으로 쓰고 오렌지는 핵심 수치 강조용으로 제한
- 배경: 공식 조감도·위치도·구역도·노선도가 승인되면 사용하고, 없으면 네이비 그리드/도시 브리핑 배경 사용
- 기사 이미지가 없거나 사용 조건이 불명확하면 도시 실루엣, 지도 곡선, 역세권 링 같은 자동 생성형 비주얼을 저투명 배경으로 사용한다.
- 레이아웃: 표보다 카드형 정보 블록, 체크리스트, 숫자 강조 패널을 우선 사용
- 문장: 자극적이되 과장 금지. 확정·검토·추진·협의 상태를 분리해서 표현

## 기본 5장 구성

1. 표지
   - 질문형 또는 변화 중심 제목
   - 1:1 피드 크롭 안전영역 안에 핵심 제목 배치

2. 핵심 변화
   - 분류, 지역, 출처, 키워드를 카드형 정보 블록으로 정리

3. 숫자 체크
   - 물량, 일정, 금액, 거리, 단계 등 기사에서 확인 가능한 수치만 강조
   - 불확실한 수치는 “원문 기준 확인”으로 처리

4. 확인 필요사항
   - 확정인지 검토인지, 일정 변경 가능성, 이미지 사용 조건 등을 분리

5. 핵심 요약
   - “저장용” 문구는 사용하지 않음
   - 원문에서 다시 확인할 항목을 짧게 정리

## 이미지 사용 원칙

- 뉴스 기사에 포함된 이미지라도 공식 원문에서 발췌된 조감도, 위치도, 구역도, 노선도만 사용한다.
- 출처·사용 조건이 불분명하면 자동 사용하지 않고 확인 요청 또는 `REVIEW.md`에 기록한다.
- 일반 현장 사진, 인물 사진, 장식용 사진, 언론사 자체 촬영 사진은 사용하지 않는다.
- 승인된 기사 이미지를 쓸 때도 텍스트 가독성을 우선한다. 이미지는 어둡게 처리하고 낮은 투명도 또는 강한 오버레이를 적용한다.
- 기사 이미지를 쓰지 않는 경우에는 저작권 걱정이 없는 코드 생성형 추상 배경을 사용한다.

## 캡션 규칙

- 첫 줄: 지역 + 기사 제목
- 본문: 핵심 요약 bullet
- 확인 안내: 단계, 일정, 수치가 확정인지 검토인지 다시 확인하라는 문장 포함
- 이미지 안내: 공식 조감도·위치도·구역도·노선도만 사용한다는 기준 포함
- 마지막: 출처, 원문 링크, 관련 해시태그
- 해시태그는 고정 태그만 반복하지 않고 기사 내용에서 지역, 역명, 사업유형, 청약/교통/정비사업 키워드를 추출해 추천한다.
- 해시태그는 10~14개 안쪽으로 제한한다. 너무 많은 태그는 스팸처럼 보일 수 있으므로 공통/지역/주제/검색형 태그를 섞는다.

## 해시태그 추천 기준

- 공통: `#부동산뉴스`, `#주택공급`, `#부동산브리핑`
- 지역: `#서울`, `#인천부동산`, `#검암역세권`처럼 기사에서 확인되는 지역·역명
- 주제: `#청약`, `#분양`, `#재개발`, `#재건축`, `#정비사업`, `#교통호재`, `#신도시`
- 검색형: `#청약일정`, `#분양정보`, `#공급일정`, `#원문확인`
- 애매한 내용은 해시태그로 단정하지 않는다. 예를 들어 검토 단계의 철도 이슈를 `#착공확정`처럼 쓰지 않는다.

예시:

```text
서울 모아타운 공급 일정이 빨라질까?

▪ 서울시, 모아타운 착공 목표 발표
[핵심]
기사 기준으로 공급 물량, 착공 목표, 추진 단계를 구분해서 봐야 합니다.

▪ 확인할 것
발표·검토·확정 단계를 원문 기준으로 다시 확인하세요.
이미지는 기사 내 공식 조감도·위치도·구역도·노선도만 사용합니다.

출처: 매체명
원문 링크

#부동산뉴스 #주택공급 #서울부동산 #정비사업 #모아타운
```
