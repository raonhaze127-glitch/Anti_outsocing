# 카드뉴스 레이아웃 QA 규칙

이 문서는 부동산 공급 뉴스 카드뉴스를 자동 생성할 때 반복해서 지켜야 할 형식 검수 기준이다.

## 표 카드 텍스트 규칙

- 표 카드의 왼쪽 라벨은 독자가 바로 이해할 수 있는 명칭으로 쓴다.
  - 예: `블록` 대신 `블록명`
  - 예: `지역`보다 구체적으로 필요하면 `위치`, `대상지`, `사업지`
- 긴 지명, 사업명, 블록명, 노선명은 브라우저 자동 줄바꿈에 맡기지 않는다.
  - 잘못된 예: `의정부우정 공공주택지구 A-` / `2`
  - 좋은 예: `의정부우정 공공주택지구` / `A-2`
- 의미 단위 줄바꿈이 필요하면 슬라이드 데이터의 값에 `{br}`을 넣어 직접 줄을 나눈다.
  - 예: `블록명|의정부우정 공공주택지구{br}A-2`
- 한 줄 안에서 하이픈 뒤 숫자만 떨어지는 형태는 금지한다.
  - `A-2`, `B-1`, `GTX-C` 같은 표기는 한 덩어리로 보이게 한다.

## 표 카드 정렬 규칙

- 2×2 표 카드의 각 박스는 내부 텍스트를 세로 가운데 정렬한다.
- 한 박스만 두 줄이 될 경우에도 다른 박스와 시각적 높이가 어긋나 보이지 않아야 한다.
- 라벨과 값 사이 간격은 일정하게 유지하고, 값이 길어질수록 패딩을 늘리는 대신 의미 단위 줄바꿈을 우선 적용한다.

## 렌더링 후 눈검수 체크

- 제목·본문이 1:1 피드 안전영역 안에 들어오는지 확인한다.
- 긴 단어가 한 글자 단위로 쪼개지지 않았는지 확인한다.
- 숫자와 단위가 분리되지 않았는지 확인한다.
  - 예: `463세대`, `4억300만원`, `59㎡`, `A-2`
- 동일한 표 안에서 특정 카드만 위쪽으로 떠 보이거나 아래로 처져 보이면 중앙 정렬 또는 문구 길이를 조정한다.
- 수정한 레이아웃 규칙은 스크립트에 반영해 다음 생성물에도 자동 적용되게 한다.

## 사업 단계·사업형태 표현 규칙

- 기사 제목이나 본문에 나온 사업형태·절차명은 표지와 핵심 요약에서 생략하지 않는다.
  - 예: `신속통합기획`, `신통기획`, `모아타운`, `모아주택`, `공공주택지구`, `도심복합사업`
- 특정 절차가 확정된 기사에서는 그 절차명을 그대로 살린다.
  - 잘못된 예: 기사 내용은 `신통기획 확정`인데 카드 제목을 `재개발 확정`으로 작성
  - 좋은 예: `사당동 신통기획 확정`
- `재개발 확정`, `재건축 확정`, `분양 확정`처럼 사업 전체가 최종 확정된 것처럼 보이는 표현은 원문에서 해당 단계가 명확히 확인될 때만 쓴다.
- 정비사업 콘텐츠는 `사업형태/절차명`과 `후속 인허가 단계`를 구분해서 작성한다.
  - 예: `신통기획 확정은 중요한 진전이지만, 정비구역 지정·사업시행인가 등 후속 절차 확인 필요`
